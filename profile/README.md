# Elan Registry

This is the Registry for the 1963 thru 1973 Lotus Elan and the 1967 thru 1974 Lotus Elan Plus 2. The purpose of the registry is to keep a history of the cars, trace the evolution of the Lotus Elan and to facilitate owner communication.

The Lotus Elan Registry started in January 2003. A thread on LotusElan.net asked the question, "Does anybody know if there is a Lotus Elan register?" I bashed together a registry and 23 years later we have over 1590 cars accounted for with more added every month.

## Projects

- **registry** — the main Elan Registry web application: car registration,
  ownership history, and member tools. *(Migrating here from `unibrain1/ElanRegistry` soon.)*

---

Elan Registry traces its roots back to the original **Type 26 Register**, one
of the earliest online resources for Elan owners — Lotus's internal project
code for the Elan was "Type 26."
